WhalesCoin V3 - Professional Admin Edition

Files:
- index.js
- package.json

Highlights:
- Premium crypto commands and inline menus
- Direct /btc /eth /sol style coin lookup
- Live market data through CoinPaprika
- Automated anti-link, anti-spam and blocked-phrase moderation
- /admin protected Admin Center
- Admin dashboard, moderation center, command guide and recent action logs
- /block and /unblock controls
- No MongoDB/database required

Deployment:
1. Replace index.js and package.json in GitHub.
2. Commit changes.
3. Render -> Manual Deploy -> Deploy latest commit.
4. Keep BOT_TOKEN and TELEGRAM_WEBHOOK_SECRET in Render Environment Variables.

Important: Admin statistics/logs and alerts are memory-only and reset when the Render service restarts.

# WhalesCoin Professional Bot v3.1

Owner: @DesignerPlusDev
Website: https://whalescoin.io
Community: https://t.me/WhalesCoinTalks

Features: live crypto cards, compact coin images, price/market/volume/supply/about/links buttons, trending, moderation, admin panel, Render webhook, no database.

Render Build: npm install
Render Start: npm start
Node: 20+

Required Environment Variables:
BOT_TOKEN
TELEGRAM_WEBHOOK_SECRET
RENDER_EXTERNAL_URL
BOT_OWNER_USERNAME=DesignerPlusDev
BOT_OWNER_ID= (optional)
WEBSITE_URL=https://whalescoin.io

Telegram bot must be group admin with Delete Messages + Ban/Restrict Users permissions.
